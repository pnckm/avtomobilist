# Автомобилист · КХЛ

Статический дашборд: календарь матчей, статистика игроков и подробная турнирная таблица КХЛ с процентом набранных и потерянными очками. Матчи открываются в протоколах на сайте КХЛ.

## GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория, в ветку `main`.
2. В `Settings → Pages` выберите `Deploy from a branch`.
3. Выберите ветку `main`, папку `/ (root)` и нажмите `Save`.
4. Откройте ссылку, которую покажет GitHub после публикации.

Сборка и установка зависимостей не нужны. Все пути относительные, поэтому сайт работает по адресу `https://<login>.github.io/<repository>/`.

Разделы используют хеш-маршруты: `#overview`, `#calendar`, `#players`, `#table`.
Данные загружаются в браузере из публичного API КХЛ/Webcaster. Нужен интернет; первая загрузка состава и календаря может занять 10–15 секунд.

## Локальный просмотр

Запустите из этой папки `python3 -m http.server 4173` и откройте `http://127.0.0.1:4173/`.
